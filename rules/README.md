# rules/

Project rules for agents working in this repo. Read this file first, then open only the files that match the task.

## Load order
1. `AGENTS.md` (structure, conventions, ANTI-PATTERNS) and the nearest `VoiceInk/<area>/AGENTS.md` for the folder you edit.
2. `rules/project/*` - product facts and invariants of this fork.
3. `rules/common/*` - how changes are made and verified here.
4. `rules/roles/*` - only when acting in that role.

## Harvesting
New entries come only from the user-invoked `/update-revise-rules`. Do not add session notes here by hand.
